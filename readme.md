# advent of code

solutions for [advent of code](https://adventofcode.com)

usage:

```
aoc.ps1 <part> <date> [year]
```

to automatically download puzzle inputs, add a `/session-cookie` file with your session cookie from `adventofcode.com` via dev tools > application > storage > cookies. alternatively, download input files to a `/data/<year>/` directory using the two digit date as the file name (e.g. day 2 = "02").
